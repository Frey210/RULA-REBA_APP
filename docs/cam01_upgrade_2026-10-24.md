## Pairing Versi Baru

State lama menyimpan paired=true tetapi tidak memiliki device_token. Nilai paired
lama bukan bukti kontrol terautentikasi sudah tersedia. State ini tidak dihapus
atau diubah menjadi unpaired sebagai bypass.

Profil backend installer masih memiliki record CAM_01 berstatus pairing_required,
tanpa UUID/credential_nonce/hash kontrol baru, dan alamat lama 192.168.1.13.
Ini perlu diselesaikan lewat pairing normal dari akun pemilik:

1. Gunakan aplikasi 0.2.3 dan login ke akun pemilik CAM_01.
2. Devices > Scan LAN, temukan CAM_01 / ergoquipt-rr pada 10.55.0.1.
3. Create pairing code > Pair CAM_01. Alamat baru dan kredensial baru disimpan
   melalui alur backend yang memvalidasi pemilik; tidak perlu menghapus kamera.
4. Setelah ready, pilih Preview camera atau buat sesi uji.

Belum ada klaim bahwa sesi inferensi/ingest CAM_01 lulus sebelum pairing versi
baru selesai. Nama hostname lama tidak menghalangi pairing berbasis UUID.
